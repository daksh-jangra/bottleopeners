    How it works
    
        
    The tool runs a pipeline that reads a page, scores how quotable it is to AI answer engines, fixes it, and proves the improvement.
    
        
    
          
    The tabs
    
          
    Analyze
    Reads any page and scores it 0–100 on six citation-readiness signals, with fixes ranked by how many points each is worth.
    
          
    Rewrite
    Claude rewrites the weak parts (generic headings, buried answers) and we re-score to prove the lift. Consumes API credit.
    
          
    Schema
    Generates ready-to-paste JSON-LD structured-data markup so Google understands the page.
    
          
    Report
    A shareable one-page client report — score, grade, ranked fixes, schema — you can download as HTML.
    
          
    AEO Audit
    The same signals as a pass/warn/fail checklist — structure, schema, Open Graph, canonical, HTTPS/HSTS, JS-free rendering — grouped by category and exportable as CSV. Free, no API credit.
    
          
    Competitors
    Asks Claude your customers' questions with live web search and shows which rival domains win the citations. Slow (live search) and consumes credit.
    
          
    Sentiment
    Gets each AI answer to your customers' questions, then classifies how your brand is portrayed — positive, neutral, or negative.
    
        
    
        
    
          
    What the score does and doesn't mean
    
          
    The score measures on-page content signals — not real-world ranking or domain authority. A page can score low and still rank well if it has strong backlinks (and vice-versa). Use it to make content more quotable, not to predict rankings.
